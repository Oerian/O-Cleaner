# O-Cleaner 长期发展路线图（v2.18 基线）

本文档定义自 **v2.18（现行稳定基线）** 起的中长期演进方向与阶段规划，并持续守住项目底线：**零第三方运行时依赖、不默认自动删用户文件、所有变更可解释/可验证/可撤销**。

---

## 一、v2.18 当前已落地能力基线

- **核心扫描与三引擎体系**：管理员下基于自研 NTFS `$MFT` C 双缓冲加速引擎（ABI v5），普通权限下集成纯 Win32 `WinVerifyTrust` 验签的 WizTree 便携版，加之 `os.scandir` / PowerShell 兜底；支持跨设备速度自动校准。
- **17 模块标准库架构**：无环基础层 `runtime.py` + 16 个高内聚业务域模块 + `web/js/i18n.js` 零构建拆分，配齐从编码契约到 AST F821、全量 `selftest.py` 与双语 Edge CDP 的工程门禁体系。
- **三大功能视图 + 8 项分析中心工具**：扫描概览、游戏占用概览（Steam / Epic / GOG）、分析中心（大文件排行、重复大文件、应用专清、毒瘤清除、磁盘快照对比、下载目录整理、Junction 无损搬家、官方组件系统瘦身）。
- **全链路安全与可逆保障**：9 层路径护栏、高风险默认进回收站（含按原始路径还原与清理后定向清空）、DPAPI 凭据加密、GitHub Gist 双向同步与脱敏社区分享、GUI 数据目录迁移与整机备份还原。

---

## 二、中长期版本规划

### 1. v2.19：前端容器重构与交互体验深度打磨（近期优先）
- **分析中心脱离 `#modal` 承载结构**：当前 8 项分析工具借用 `#modal` 与 `.mbody` 动态挂载，导致 DOM 结构耦合且弹窗状态切换复杂。将引入独立持久容器 `#analysisStage`，与确认/详情弹窗 `#modal` 彻底解耦。
- **原生 `confirm()` / `prompt()` 全面升级为界面内模态组件**：替换前端剩余 16 处浏览器原生弹窗，统一视觉主题、无障碍 `aria-modal` 与键盘焦点管理（默认聚焦安全选项）。
- **操作可中断与实时进度可视化**：
  - 将前端 `AbortController` 扩展为后端扫描会话令牌，允许用户一键真正中止运行中的磁盘遍历、MFT 读取或大批量删除任务；
  - 清理、重复文件全量 SHA-256、Windows 官方 `DISM` 瘦身提供分步进度百分比、当前处理路径与可中断反馈。
- **撤销 / 还原与历史回执直达闭环**：删除入回收站或执行 Junction 搬家 / 下载归档后，顶部通知与结果页提供单键跳转/撤销按钮；`sys_slim_run` 清理释出的字节数同步写入清理历史与审计回执。
- **首屏聚焦与智能折叠**：无警告时自动折叠非关键提示横幅，提升 1366×768 小屏笔记本上的首屏可视占用排行行数。

### 2. v2.20：主动空间管家与软件级细粒度治理（中期）
- **多盘统一总览视图**：增加「全机存储健康仪表盘」卡片，跨盘横向对比 C/D/E 盘可用比例、7 日净增长斜率与积压可清理体量。
- **应用级专项规则扩展与精细控盘**：
  - 扩展开发者工具生态（VS Code / JetBrains / Cargo / Go / Gradle / Maven / Composer / conda 缓存安全拆解）；
  - 基于社区已验签资源包与本机软件清单匹配，在扫盘前优先提示高匹配度的专项包。
- **定时任务精细化策略与低扰动运行**：支持按周/开机后空闲时段触发、低电量/高 CPU 自动避让，以及单条规则独立的增量日志汇总卡片。
- **本地增量磁盘热点追踪**：轻量复用快照差异，支持对用户指定重点目录的周级涨跌曲线查看。

### 3. v3.0+：生态信任、系统集成与原生化分发（远期）
- **代码签名与官方包管理器分发**：推动构建签名版安装包（消除 SmartScreen 未知发布者警告），并接入 `winget` 与 `scoop` 清单以支持命令行一键升级。
- **已签名社区规则与资源包生态**：为扩展知识库与 `packs/` 引入发布者签名与 SHA-256 清单校验，允许用户在图形界面浏览、订阅并自动验证社区规则更新（保持「不可提升已有条目 `cleanable`/`risk` 权限」的防投毒边界）。
- **更多 PC 游戏平台与着色器治理**：扩展 Xbox Game Pass / Battle.net / EA App / Ubisoft Connect 安装清单与孤儿残留识别，精细拆解 NVIDIA/AMD 跨驱动残留着色器缓存。
- **原生级桌面外壳演进**：探索更轻量可控的系统级 WebView2 原生外壳封装，彻底告别端口竞争与外部浏览器安装路径探测。

## 三、刻意不做的边界（长期原则）

| 能力 | 决策与原则说明 |
|---|---|
| 启动强制 UAC 提权 | 永远先以普通权限打开界面让用户看清可释放体积，再按需一键提权。 |
| 后台静默自动强杀进程 | 工具**绝不自动强杀任何正在运行的进程**；仅有文件被占导致删除受阻时列出启发式候选进程，经用户显式勾选非系统关键进程并二次确认后才会通过 Fail-Closed 白名单尝试结束。 |
| 无用户确认的静默清空系统 | 除用户显式启用并配置的定时「安全预设」任务外，常规交互下必须经过确认弹窗展示精确路径、文件数与体积。 |
| 后台遥测与行为采集 | 不收集、不上报任何磁盘路径、软件清单或个人使用数据；所有出网请求均须用户显式点击触发。 |
| 第三方运行包依赖（pip / npm） | 坚持纯 Python 标准库与零构建 Web 前端，便携压缩包即解即用。 |
