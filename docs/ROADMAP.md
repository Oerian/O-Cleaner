# O-Cleaner 远景规划与后续发展路线图（Roadmap）

> **规划基线**：v2.16（`2026-11-20`，`main` 分支 `56e4cb9`）  
> **核心基因**：**零第三方运行时依赖** · **硬边界防误删** · **100% 本地隐私** · **可逆与精细化治理闭环**  
> 所有后续演进均以「真实用户痛点 + 不破坏安全底线」为前提，不承诺固定排期；欢迎通过 Issue 讨论优先级，贡献规范见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

---

## 一、产品定位与长期愿景

与 CCleaner / WizTree / 微软 PC Manager 等同类工具相比，O-Cleaner 的差异化定位是：

1. **零安装、零依赖、拷走即用**：仅依赖 Python 3.8+ 标准库（或内嵌官方 embeddable 运行时），不写注册表、不装后台服务、无第三方 `pip`/`npm` 依赖链。
2. **看得懂再决定删不删**：不止展示目录体积，更通过 42 条内置规则 + 172 条可扩展资源包 + 自有 AI 释义，回答「它是什么 / 能否重建 / 删了有什么影响 / 何时建议保留」。
3. **可逆、可追溯、宁保守不误删**：九层删除护栏 + 锁定文件预检 + 三态原子删除（断电自愈）+ 回收站原位还原 + 逐项 JSON 回执。
4. **从「清理工具」演进为「本地智能空间管家」**：未来从被动扫描清理，升级为「空间异常预测 + 软件行为级精细治理 + 社区共享知识生态」。

## 二、现状基线（v2.18，2026-11-26）

- **三大功能视图**：
  - **扫描概览**：全盘排行 + 逐层下钻 + 就地懒加载展开 + 跨层级实时搜索；WizTree / 自研 NTFS MFT 直读 / `os.scandir` 三引擎择快与跨机自动重校准；磁盘概览占比环 + 环右三页签图表坞（剩余空间趋势 / 清理记录 / 类型分布）；系统隐藏项合并展示；自定义聚合组与右键个性化覆写。
  - **游戏占用概览**：Steam / Epic / GOG / 自定义库合盘展示、中文译名、正方形封面缩略图、卸载残留与久未游玩大作统一「回收建议」、删前疑似存档探测、体积趋势与 CSV/Markdown 导出。
  - **分析中心**：七项专项工具面板化统一呈现（大文件排行 / 重复大文件 / 应用专清 / 毒瘤清除 / 磁盘快照 / 下载整理 / 磁盘迁移），带会话缓存与 `_anSeq` 防串台守卫。
- **安全与工程底座**：`ocleaner/` 14 模块标准库架构 + `app.py` 兼容入口；Host/Origin 双守卫；Windows DPAPI 凭据加密；50 项护栏矩阵 + 53 项秒级单测 + 63 项 linter 缺陷注入 + 595 项全量自测 + 135 项真实浏览器 CDP 验收；CI 快慢两级门禁。

## 三、后续发展规划（v2.17 → v3.0+）

### 阶段一：v2.17 —— 架构收尾与跨机验证（近期，低风险高收益）

1. **后端分析域与路由层拆分（`ocleaner/analysis.py` + `ocleaner/server.py`）**
   - 当前 `ocleaner/core.py` 约 7,900 行，其中分析中心专项逻辑（应用专清 / 毒瘤清除 / 搬家 / 下载归档 / 重复文件 / 快照 / 搜索）与 HTTP `Handler`（约 1,400 行）职责独立。
   - 拆出后 `core.py` 降至 ~4,500 行，大幅降低后续维护与小模型上下文负担，同时保持 `app.py` 全符号 re-export 与 `check_undefined.py` 零破坏。
2. **签名库规则 Linter 扩展**
   - 将新增的 `config/appclean.json` 与 `config/bloatware-builtin.json` 接入 `tools/lint_rules.py` 结构与安全校验（例如禁止将 `Msg` / `db_storage` / AI 模型权重目录标为 `cache`）。
3. **跨设备实测补盲**
   - 在至少一台非中文区域 / 非管理员 / 单盘（仅 C 盘）Windows 机器上完整验证 `doctor.py`、`selftest.py`、`cdp_check.js` 与免安装版 `make_exe.py` 产物。

### 阶段二：v2.18 —— 智能空间洞察与自动化闭环（中期）

1. **主动预测性磁盘维护（基于快照历史）**
   - 利用已落盘的 30 天目录快照与每日剩余空间趋势，计算盘符「预计剩余天数」与目录周均增速；当某缓存目录连续 ≥3 次回涨（`hot`）或系统盘剩余空间低于阈值（如 10% / 15 GB）时，在界面顶部或托盘气泡主动提醒，并一键生成定时清理规则建议。
2. **软件级行为语义引擎**
   - 将识别能力从「目录名/路径匹配」升级为「结构 + 行为语义分层」：对同一软件自动拆出 `cache`（绿：随时可清）、`attach/media`（黄：按时间/体积筛选清理，如清理 90 天前的微信图片/视频）、`core/db`（红：硬锁不可删）。
3. **大文件与重复文件体验深化**
   - 重复大文件支持按扩展名/目录筛选、按「保留最新/保留最早/保留指定目录」一键智能勾选副本；大文件排行支持自定义体积门槛与扩展名过滤。
4. **定时任务与托盘增强**
   - 托盘右键菜单支持显示最近一次清理结果、按盘选择安全清理、暂停/恢复定时任务；补齐 Windows 任务计划程序一键注册/卸载向导脚本（不改系统服务，纯计划任务 XML）。

### 阶段三：v3.0+ —— 生态化与桌面级体验（远期）

1. **资源包社区生态与信任分级**
   - 在 `Oerian/O-Cleaner-packs` 仓库上线 GitHub Actions PR 自动验收（复用 `tools/packs_ci_validate.py` + `lint_rules.py --strict`）；
   - 客户端引入资源包信任分级（内置 / 官方已验签 / 用户自导入）与更新失败自动回滚。
2. **多平台游戏库拓展**
   - 在保留现有 Steam / Epic / GOG 零依赖清单解析基础上，按样本条件逐步扩展 Ubisoft Connect、EA App、Battle.net 与 Xbox/MS Store 游戏识别与存档位置提示。
3. **发行渠道与信任背书**
   - 评估开源代码签名（SignPath 等免费开源签名计划）以消除 SmartScreen 警告；
   - 具备稳定发布节奏与签名后，推进 `winget` / `scoop` 清单收录，提升安装与升级体验。
4. **单文件 / 跨平台子集评估（按需）**
   - 保持当前「免安装绿色目录（内嵌官方 Python）」为主力发行形态；仅在确认杀软误报与体积可控时再评估单文件封装；跨平台（Linux/macOS 空间分析子集）仅在抽象平台层不影响 Windows 核心体验的前提下探索。

## 四、明确不做的事（非目标）

- **绝不采集遥测**：不加入任何统计上报、埋点或静默联网行为。
- **不做账号体系与自建云服务**：数据完全归属本地目录，可选云同步仅通过用户自己的 GitHub 私密 Gist 完成。
- **不代用户强杀进程**：文件被占用时仅做可靠探测 + 进程候选提示，关闭软件的决定权永远留给用户。
- **不引入重型第三方运行时依赖**：后端坚持 Python 标准库、前端坚持零构建单文件 HTML/CSS/JS，测试坚持系统自带 Edge + Node 原生 CDP。
- **绝不放松安全底线**：任何新功能、资源包或 AI 能力都不得绕过 `check_deletable` 硬保护与用户显式二次确认。
