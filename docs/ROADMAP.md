# O-Cleaner 路线图（Roadmap）

> 规划基于当前基线 **v2.15**，按「近期 / 中期 / 远期」三档排列。
> 顺序不承诺时间表；实际取舍以「用户真实痛点 + 不破坏安全边界」为准。
> 欢迎通过 Issue 讨论优先级，贡献流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

## v3.0+ 展望方向（2026-11-07 竞品分析后增补）

- **软件级行为语义引擎**：清理项从路径匹配升级为行为语义识别（缓存/附件/记录/配置），结合应用专清的 cache/data/core 三级分层，输出绿/黄/红智能推荐。
- **主动预测性磁盘维护**：基于快照 Diff 的回涨数据学习各目录增长模式，在空间告急前主动提示可清理项。
- **生态与签名**：资源包社区 PR 自动校验流水线（lint_rules --strict + 冲突路由验证 + SHA-256 摘要）；代码签名与 winget/scoop 收录（待外部资质）。
- **竞品定位锚点**：与 CCleaner/WizTree/PC Manager 相比，O-Cleaner 的差异化在「零运行时依赖 + 硬边界安全 + 本地隐私 + 精细化安全闭环」——所有演进方向不得偏离这四条基因。

## 现状基线（v2.15，2026-11-07）

- 空间分析：全盘排行 + 逐层下钻 + 行内就地懒加载展开，快速扫描（1 层）+ 深层现场扫描；三引擎（`os.scandir` 递归 / WizTree 查表 / 内置 MFT 直读）实测择快、跨设备自动重校准、用户可自选；磁盘概览占比环 + 环右组件图表坞（剩余空间趋势 / 清理记录 / 类型分布三页签）；大文件排行（支持时间段过滤）、重复大文件检测（同体积预筛 + 首尾 1 MB 采样哈希证实）与下载目录整理建议。
- 清理执行：预设 + 自定义目录 + 排行勾选三种入口；嵌套去重；锁定文件预检整体中止（含游戏本体删除）；三态删除流程（预写日志 → 原子改名 → 递归删除 → 残留如实上报 / 启动自愈）；子树重解析点（Junction/Symlink）仅摘挂载点防穿透。
- 识别体系：内置 42 条规则 + 5 组资源包（172 条）；三层释义优先级；支持右键自定义徽章/配色/提级置顶与整目录永久排除；游戏库（Steam / Epic / GOG / 自定义）合盘展示与卸载残留检测。
- 辅助能力：被占用文件探测与进程候选提示；定时任务（带后台完成横幅汇报）；AI 助手（自带 API Key，支持 DeepSeek / 本机 Ollama 快捷预设，仅勾选不执行）；云端同步（用户自备 GitHub 私密 Gist 双向合并同步）；本机敏感凭据（AI 密钥、Gist 令牌）经 Windows DPAPI 加密落盘，防拷机泄露。
- 工程：零第三方依赖（纯标准库 `ocleaner/` 模块化包 + `app.py` 兼容入口）；进程内 `os.scandir` 测量免除 PowerShell 冷启动开销；单文件双语前端（含键盘导航与弹窗焦点陷阱）；CI 两级流水线（快级含编码契约、`lint_rules.py`、`_lint_selftest.py`、`guard_matrix.py` 50 项护栏矩阵、`unit_test.py` 24 项秒级单测；慢级含 `selftest.py` 与 `cdp_check.js`）；GitHub Releases 发布通道与「检查更新」闭环。

## 已完成（近期 / 中期规划兑现）

- **GitHub Releases 发布通道**（v2.10 起）：两档分发包挂 Releases，「检查更新」读取最新版说明。
- **大文件排行**（v2.10）：全盘最大的 N 个单文件视图（支持按近 7 / 30 / 90 天过滤）。
- **知识库长文本双语补全**（v2.10）：英文界面下规则与释义无中文残留。
- **游戏占用概览大版本**（v2.10）：回收建议统一清理出口、残留主动提醒、异常增长提醒、清单导出、排序方向、折叠记忆。
- **自有 MFT 直读引擎**（v2.11）：免第三方组件秒级全盘扫描；扫描引擎架构定稿（默认 WizTree + 实测择快 + 用户自选 + 换机自动重校准）。
- **磁盘概览组件图表坞**（v2.11）：占比环 + 剩余空间趋势 / 清理记录 / 类型分布三页签。
- **重复大文件采样哈希检测与下载整理建议**（v2.11）：基于扫描缓存的同体积预筛 + 首尾 1 MB 采样哈希证实，以及下载目录顶层自动归类建议。
- **纵深安全加固与模块化架构演进**（v2.11）：HTTP `Host`/`Origin` 双守卫、DPAPI 凭据加密、进程内 `os.scandir` 测量加速、`ocleaner/` 标准库包拆分与 `unit_test.py` 秒级单测层。
- **v2.12「可逆与精算版」**（2026-11-07）：回收站一键原位还原（Undo Clean，$I 元数据按原路径精确匹配）；目录级扫描快照对比与「近期暴涨」视图（含 🔄 高频回涨标记）；占用排行跨层级实时搜索；重复大文件三级分桶（采样→全量 SHA-256）与勾选清理。
- **v2.15「深度治理与空间腾挪版」**（2026-11-07）：应用专清视图（微信/开发者缓存 10 类签名，cache/data/core 三级语义）；C 盘无损搬家助手（占用预检→整树拷贝→双向校验→Junction→一键迁回，支持合并+冲突重命名）；Canvas 矩形树图；下载整理勾选清理与一键按类型归档（可撤销）；`--auto-clean` 无头单次清理；Edge App 无边框窗口模式；`ocleaner/` 拆分收官（10 模块：core/engines/guard/deleter/store/measure/credentials/games/integrations/ps_scripts）。

## 近期（下一两个版本）

1. **删除回执的可追溯性**
   - 逐项回执 JSON 已落盘（`receipts/`），补界面侧的按次回看与检索；
   - 为「误删反悔」提供依据（高风险项已有回收站兜底，清单补足中低风险项）。

## 中期

2. **重复文件检测（哈希级）**
   - 同体积预筛 → 部分哈希 → 全哈希三级流水，控制大盘开销；
   - 只报告不自动删，交由用户勾选。
3. **「回涨」洞察**
   - 基于已有磁盘趋势数据，标记「清理后持续回涨的目录」，生成针对性建议（如某缓存每周回涨 2 GB）。
4. **资源包生态**
   - 包签名与信任分级（内置 / 已验证 / 未验证）；社区贡献包的提交流程；
   - 在线更新已有雏形，补齐完整性校验与回滚。
5. **本地模型接入（Ollama 等）**
   - AI 助手已支持自定义 Base URL；补一组本地服务预设与连通性自检，让离线机器也能用上释义能力。

## 远期

6. **exe 单文件发行**（此前暂缓；内嵌运行时免安装版已稳定，单 exe 待权衡）
    - 内嵌运行时 vs 单 exe 的体积 / 启动速度权衡；SmartScreen 声誉积累策略。
7. **扫描快照对比**
    - 保存两次扫描快照，展示「这段时间什么变大了」，把趋势图从盘级细化到目录级。
8. **可移植性探索**
    - 抽象平台相关层（回收站、锁定探测、系统目录），评估 Linux / macOS 子集可行性；
    - 仅在核心体验不打折的前提下推进，不承诺。

## 非目标（明确不做）

- **不采集遥测**：不加入任何上传用户数据的行为，这是产品定位的一部分。
- **不做账号体系 / 自建云服务**：数据迁移始终是「整个目录拷走」；云端同步仅作为可选增强，凭用户自己的 GitHub Gist 完成，令牌只存本机。
- **不代用户结束进程**：只列候选，杀进程的决定权永远在用户。
- **不引入第三方运行时依赖**：后端坚持纯标准库，例外须有压倒性理由并写入文档。

## 维护原则

- 版本节奏：功能修复随时本地提交；**门禁全跑 + 推送 + CI + 重建发行包只在版本更新时做**。
- 断言规模持续增长，文档与提交说明不写死断言总数，以「失败 0 即绿」为判定口径。
- 安全边界（永不删除清单、AI 只勾选不执行、资源包不可改写已识别结论）是硬约束，任何新功能不得绕过。
