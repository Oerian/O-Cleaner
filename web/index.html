一键预设

AI 助手 可选

接入自己的 AI 服务（任何兼容 OpenAI Chat Completions 的接口）， 用它解释可清理项、按你的需求生成清理方案。密钥只存在本机 config/ai.json，除了你填的接口地址外不发往任何地方。
怎么接入？—— 接入引导
  1. 拿一个 OpenAI 兼容接口：DeepSeek 在 platform.deepseek.com 注册并「创建 API key」；本机 Ollama 无需密钥。
  2. 点上面的「DeepSeek」或「Ollama」快速填接口地址（也可手填任何兼容地址）。
  3. 把密钥粘进「密钥」框 —— 它只存本机 config/ai.json，只发给你填的接口。
  4. 点「获取列表」自动识别可用模型，从下拉建议里选一个（DeepSeek 通常是 deepseek-chat；想用推理模型选 deepseek-reasoner）。
  5. 勾选「启用」→「保存」→「测试连接」。

规则 · 预设 · 资源包

把当前勾选的清理项存成一条规则，以后一键套用；勾选「保存后立即清理」 则保存时直接清理这些项。
云端同步（GitHub Gist · 双向）
把换算单位、释义覆盖与固定项规则存到你自己的 GitHub 私密 Gist， 多台设备互相同步。需要一个带 gist 权限的 个人访问令牌， 令牌只存本机 config/sync.json，不经过任何第三方。 双向同步 = 拉取合并（远端逐项并进本地，不覆盖你本地的已有项）→ 把合并后的全集推回；删除不传播。
导入 / 导出自定义数据（含换算单位与释义）
把换算单位、释义/结论覆盖和固定项规则打包成一个 JSON， 便于换机迁移或让 AI 按规范生成后导回。格式见 docs\CUSTOMIZE.md；导入时逐项校验，不合格的会说明原因。

用户文档、图片、桌面目录、已安装程序本体、AI 模型权重及 Windows\Installer、WinSxS 等系统关键目录受内置保护机制严格拦截，执行前亦需二次确认。
