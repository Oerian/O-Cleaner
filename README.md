![Platform](https://img.shields.io/badge/platform-Windows%2010%20%2F%2011-0078D4)

![License](https://img.shields.io/badge/license-MIT-64748b)

Windows 磁盘空间分析与安全清理工具。基于本地 Web 界面交互，绿色免安装，不写入冗余注册表或系统服务，整个目录复制即可跨设备使用（界面内置中文 / English 双语切换，英文指南见 [docs/USAGE-en.md](docs/USAGE-en.md)）。

## 设计原则

- **零第三方依赖**：仅依赖 Python 标准库；免安装版内嵌官方 Python 运行时，开箱即用。
- **默认不自动删除**：所有清理项均需手动勾选并经确认弹窗二次核对；核心系统目录与个人数据受内置保护机制严格拦截，即便外部规则文件受损也不会越界。
- **隐私与凭据隔离**：无任何后台遥测；仅在用户主动触发检查更新、更新资源包、调用自配 AI 或 GitHub 同步时发起网络请求；AI 密钥与 GitHub 令牌均经 Windows DPAPI 绑定当前用户加密存储。

## 快速开始

1. **获取与解压**：推荐下载「免安装版（`win64-embed.zip`）」，解压至任意可写目录（如 `D:\O-Cleaner`，不建议放在 `Program Files` 等受保护目录）。
2. **启动应用**：双击 **`启动 O-Cleaner.lnk`** 或 **`O-Cleaner.exe`** 即可静默启动（源码版可双击 `启动 O-Cleaner.bat`）。首次运行如遇 Windows SmartScreen 提示，选择「更多信息 → 仍要运行」即可。
3. **扫描与提权**：浏览器会自动打开界面（默认 `http://127.0.0.1:8770/`）。如需清理系统目录或启用内置 MFT 极速直读引擎，点击顶部提示条的「一键提权重启」即可。

## 主要功能

- **空间占用分析**：全盘按体积排行，支持点击逐层下钻与行内就地展开；快速扫描（默认 1 层）定位占用大户，深层目录按需现场扫描；系统默认隐藏项自动合并汇总并支持展开明细；磁盘概览提供占比环与「可清理 / 建议保留 / 未识别」比例条，右侧图表坞支持「剩余空间趋势（按盘每日柱状图）」「清理记录」「类型分布（Top 12 与完整展开）」三页签切换。
- **三引擎扫描加速**：工具栏支持切换扫描引擎（默认自动择快，跨设备后自动校准）：
  - **内置 MFT 直读引擎**：管理员权限下基于 C 原生动态库直接解析 NTFS 主文件表（`$MFT`），兼具扩展名统计与目录树聚合加速，不依赖外部工具且不产生临时文件；
  - **WizTree 引擎**：无需管理员权限时可借本机或界面一键校验下载的 WizTree 便携版读取 MFT；
  - **递归扫描兜底**：标准库 / PowerShell 递归扫描，保证任何环境下均可正常使用。
- **分析中心（七大专项工具）**：
  - **大文件排行**：按近期修改时间（7 / 30 / 90 天）筛选全盘大型单文件；
  - **重复大文件**：基于扫描缓存按体积分组、首尾采样预筛并经 SHA-256 精确校验，跨目录副本自动标注保护；
  - **应用专清**：针对微信、开发者缓存等场景进行结构化拆解，区分 `cache`（可清理）与 `data / core`（受保护）；
  - **毒瘤软件清除**：先调用官方卸载程序，再按白名单清扫残留目录与卸载注册表项；
  - **磁盘快照对比**：对比前后两次扫描，以中线柱状图直观呈现各顶层目录的增长与回落；
  - **下载目录整理**：按文件类型自动归类并支持一键撤销；
  - **无损目录搬家**：将大型目录批量迁移至其他分区并在原位建立 NTFS Junction 透明映射，支持一键迁回。
- **清理执行与安全闭环**：提供预定义系统目标、四组一键预设（安全 / 深度 / 开发者 / 回收站）、自定义目录及排行直接勾选，自动去重嵌套路径；高风险项默认移入回收站（支持原位还原），每次清理均在 `data/receipts/` 生成可检索的审计回执。
- **被占用文件处理**：清理遇文件锁定时，可一键排查并停止关联进程后自动重试；对系统服务锁定的顽固文件，支持登记为「下次重启时自动删除（`MoveFileExW`）」。
- **游戏库管理**：自动读取 Steam / Epic / GOG 平台清单与封面，列出体积与疑似存档位置；集中汇总卸载残留与长期未游玩项目至「回收建议」，支持清单导出（CSV / Markdown）与体积周增长趋势。
- **规则、AI 预设与社区共享**：
  - **规则 · 预设 · 资源包整合面板**：支持固定清理规则保存、自定义聚合分组、GitHub Gist 双向同步与 JSON 导入导出；
  - **AI 提示词预设与一键导入**：支持按预设（自动带入当前盘未识别清单）生成提示词、自定义编辑并保存预设，以及将外部 AI 返回的固定格式 JSON 一键导入生效；
  - **社区贡献与资源包**：内置 42 条目录识别规则与 5 组 172 条可扩展资源包，支持一键打包上传规则至 GitHub 社区（公开 Gist 或预填 Issue）。
- **定时清理与托盘常驻**：可在「定时自动清理」面板配置周期性任务，并一键开启「开机自启并最小化到托盘」。

## 界面与操作

界面采用**顶栏 + 左右双栏独立滚动 + 常驻底栏**布局：**顶栏**负责选盘、切换功能视图、主题与语言；**左侧主区**包含工具栏、磁盘概览（占比环与三页签图表坞）及当前功能视图；**右侧栏**集中放置运行环境自检、一键预设、统计信息与各类设置折叠面板。

- **三个功能视图**：顶部「扫描概览」「游戏占用概览」「分析中心」分段按钮常驻可达，点击即时切换。
- **面板目录条**：右侧栏顶部吸顶列出全部折叠面板标题，点击任意一项自动展开并滚动到位。
- **操作主线**：选盘 → 自动扫描 → 勾选待清理项（或使用右侧「一键预设」）→ 点击底部「清理选中项」→ 在确认弹窗核对路径与体积 → 查看实际释放量与贡献前三。
- **看清再删**：每行均提供「详情」说明用途、重建特性与删除影响，并支持行内「展开 ▾」就地查看子目录、「归档」进自定义聚合组或「细分查看」拆出缓存目录；「建议保留 / 未识别」项目也可手动勾选，但确认弹窗会集中红框提示并默认移入回收站兜底。
- **键盘导航**：占用排行支持 `↑` / `↓` 移动焦点、`Space` 勾选/取消、`Enter` 下钻子目录、`Esc` 逐级返回（关闭弹窗 → 返回上一级 → 返回概览），按 `/` 可在概览、游戏库或筛选框中快速聚焦搜索。

逐项操作细节见 [docs/USAGE.md](docs/USAGE.md)。

## 数据迁移与整机备份

支持在界面右侧 **「说明与数据迁移」** 面板直接完成全部迁移与备份操作：

- **图形化迁移数据目录**：输入目标路径（如 `D:\O-Cleaner-Data`）并点击「迁移目录」，即可将历史记录、磁盘趋势、快照与自定义规则迁至指定位置并自动记忆；随时可点击「恢复默认」迁回程序目录。
- **整机备份与还原**：点击「导出整机备份 (.zip)」可将全部运行数据与自定义配置打包导出（自动排除本机 DPAPI 加密密钥），在目标设备点击「导入还原备份」即可完整恢复。
- **便携随行**：未单独迁移数据目录时，直接复制整个 `O-Cleaner` 文件夹即可在其他设备开箱使用。
