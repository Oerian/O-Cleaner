**看得懂、不敢误删、上手即用的 Windows 磁盘空间分析与安全清理工具。**  
绿色免安装，不写臃肿注册表，整个文件夹拷走即可在另一台电脑上继续使用（界面支持中文 / English 一键切换，英文详细说明见 [docs/USAGE-en.md](docs/USAGE-en.md)）。

## 为什么选择 O-Cleaner

- **默认不自动删除任何文件**：所有清理都需要你亲自勾选并二次确认；不懂的目录可以先看右侧「?」的大白话解释。
- **系统与个人数据硬保护**：个人文档、照片、桌面文件、已装软件本体、AI 大模型以及 Windows 核心系统目录永远受内置保护名单拦截，删不到它们。
- **零第三方依赖，不采集隐私**：没有广告与后台遥测；本地配置的 AI 密钥、GitHub 令牌都经 Windows DPAPI 加密保存在本机，拷贝文件夹到别的电脑也不会泄露。
- **C 原生 MFT 秒级扫盘**：管理员权限下内置 C 原生 NTFS `$MFT` 直读引擎（并支持与 WizTree 自动择快），几十万文件秒级出树，不产生临时垃圾文件。

## 三步快速开始

1. **下载并解压**：推荐下载「免安装版（`win64-embed.zip`）」，解压到任意可写文件夹（如 `D:\O-Cleaner`，不建议放到 `Program Files`）。
2. **双击启动**：直接双击 **`启动 O-Cleaner.lnk`** 或 **`O-Cleaner.exe`**（无命令行黑框；若使用纯源码包，则双击 `启动 O-Cleaner.bat`）。首次运行如遇 Windows SmartScreen 提示，点「更多信息 → 仍要运行」即可。
3. **选盘、查看与清理**：在顶部选择盘符，查看空间占用与大白话说明，勾选确认可清理的项目后点击底部「清理选中项」。需要清理系统目录或使用内置 MFT 极速扫盘时，点顶部黄色提示条的「一键提权重启」即可。

## 主要功能一览

- **全盘空间占用排行与可视化**：支持按体积/名称排序、逐层下钻、行内就地展开；磁盘概览提供占比环，以及「剩余空间趋势」「清理记录」「类型分布（Top 12 与完整展开）」三页签图表。
- **分析中心七大专项工具**：
  - **大文件排行**：按近期时间过滤找出占空间的单个大文件。
  - **重复大文件**：先按体积和首尾采样预筛，再用 SHA-256 精确核验，跨目录副本自动标注保护。
  - **应用专清**：针对微信、开发者缓存等做结构化拆解，只动缓存不动聊天记录与核心数据。
  - **毒瘤软件清除**：先调用官方卸载程序，再按白名单清扫残留目录与注册表项。
  - **磁盘快照对比**：对比前后两次扫描，用中线柱状图直观看出是哪几个目录在暴涨。
  - **下载目录整理**：按类型自动归档下载文件夹，支持一键撤销。
  - **无损目录搬家**：把占空间的大目录迁到别的盘，并在原位留下透明映射，不影响软件正常打开，支持一键迁回。
- **游戏库专项管理**：自动识别 Steam / Epic / GOG 游戏体积、封面与存档位置，集中汇总卸载残留和长期未玩的大作建议。
- **被占用文件处理**：清理遇文件被占用时，可一键查找并停止占用进程后自动重试；对系统服务锁住的文件，也支持「标记为下次重启时自动删除」。
- **规则、AI 预设与社区分享**：
  - 支持保存自己的固定清理规则与聚合分组。
  - 内置「AI 提示词预设与一键导入」：可带入当前盘未识别清单生成提示词，自定义编辑保存预设，并把外部 AI 返回的结果一键导入生效。
  - 支持将整理的规则一键上传分享到 GitHub 社区，或从社区拉取扩展资源包。
- **定时清理与托盘常驻**：可在右侧「定时自动清理」面板设置定时任务，并一键开启「开机自启并最小化到托盘」。

## 数据迁移与整机备份

无需记忆任何操作技巧，直接在界面右侧 **「说明与数据迁移」** 面板即可图形化完成：

- **一键更换数据目录**：输入新的目标路径（例如 `D:\O-Cleaner-Data`）点「迁移目录」，历史记录、磁盘趋势、自定义规则会自动搬过去并记住位置，随时也可「恢复默认」。
- **整机备份与还原**：点击「导出整机备份 (.zip)」会打包全部历史、趋势、快照与自定义规则（自动跳过本机敏感密钥），换到新电脑后点「导入还原备份」即可无缝衔接。
- **绿色随身携带**：如果不单独迁移目录，直接把整个 `O-Cleaner` 文件夹复制到 U 盘或新电脑，同样开箱即用。

## 仓库目录速览（开发者参考）

- `app.py` 与 `ocleaner/`：服务入口与核心扫描/清理/MFT 引擎模块。
- `config\targets.json` 与 `config\filetypes.json`：内置清理规则、释义与文件类型知识库。
- `web\index.html`（及配套 `styles.css`、`app.js`）：本地 Web 交互界面。
- `tools\selftest.py` 与 `tools\lint_rules.py`：全量自检与规则一致性校验脚本。
